# 小智AI輔助（瀏覽器擴充功能）

## 目前實作

Chrome／Edge Manifest V3 側邊面板，點擊工具列擴充功能圖示時讀取當前分頁網址，顯示查詢流程與真實資料尚未介接的狀態。**不會自動取得房源內容、不會搜尋真實門牌、也不會聲稱完成配對。** 目前未整合會員登入，僅供開發測試，**不得作為正式會員功能公開營運**。

## 本機安裝測試

1. 下載此資料夾所有檔案至電腦同一資料夾。
2. Chrome 開啟 `chrome://extensions`（Edge 為 `edge://extensions`）。
3. 啟用開發人員模式，點「載入未封裝項目」，選取此資料夾。
4. 開啟一般房仲物件頁，點 LANDORA 擴充功能圖示，右側面板將開啟。
5. 點「開始配對」可看到目前的待介接結果；切換物件後點「重新讀取網址」。
